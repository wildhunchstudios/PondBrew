# Game Art Direction

Read the canonical AGENTS.md sections 7 and 11 plus the latest R06.5 evidence before changing presentation. Resolve these paths from the repository root; do not import another project's assets.

Inputs: the requested visual change, current source/build checkpoint, actual in-game captures, and any user reference with its provenance. The user selected cozy, colorful cartoon rooms: warm honey wood/teal/cream in the front shop; mint tiles, colorful vessels/pipes/gauges in the lab. R06.5v1 is a first pass, not approved final art. Preserve the front/back split and do not restart style discovery.

Choose one representative change before multiplying content. Preserve rounded silhouettes, readable station outlets and species shapes, and the warmer shop versus scientific lab contrast. Avoid replacing this direction with unapproved voxel/block geometry. Show an actual camera view at play distance, with the normal HUD and both lighting states relevant to the change. Label concept images separately from game captures.

Keep station roots, reach, existing interaction colliders, placement footprints, aisle/door clearance, inventory ownership and save IDs intact. Decorative children own no gameplay collider. Read ShopWorldArtDirection.cs and the owner that creates/disposes its meshes/materials. Retain URP materials and verify shader inclusion in Windows before accepting replacements.

Output: a bounded visual comparison, changed assets/source with origin/license, real capture paths/build identity, navigation/readability results and outstanding human feedback. Update AGENTS.md through the session-handoff workflow. Stop expansion when the chosen visual sample needs user feedback, provenance is unknown, or a change would alter the selected style. Paid generation and external uploads require separate explicit authorization; tool installation supplies none.
